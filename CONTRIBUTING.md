# Contributing to LifeFlow AI

Thank you for your interest in contributing to LifeFlow AI! 🚀

## How to Contribute

1. Fork this repository.
2. Create a new branch.

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes following the existing coding style.
4. Test your changes before committing.
5. Commit using clear messages.

Example:
- feat: add calendar reminders
- fix: resolve planner bug
- refactor: improve dashboard module

6. Push your branch.

```bash
git push origin feature/your-feature-name
```

7. Open a Pull Request describing your changes.

## Coding Guidelines

- Write clean and readable code.
- Keep functions modular.
- Avoid duplicate code.
- Maintain responsive design.
- Do not break existing functionality.

## Reporting Bugs

Please include:
- A clear description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

## Feature Requests

Ideas and improvements are always welcome.
